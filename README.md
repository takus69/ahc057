# AHC057

## 考察

- 結合する30個を決めると重心速度は変わらない
- 重心速度の距離より小さい距離になったら結合するのを貪欲で決定

## 解説動画視聴

- 解法2: 30個に分けてMST(560位, 466,412,675)
- 解法3: クラスタリングでグループ分けしてMST(282位, 698,308,637)
- 解法4: 解法3をいろんな時間で試す
- ポイント
  - どの点と点でつなぐか
  - どの時間でつなぐか
  - どのようにグループ分けするか
- 考察
  - サイズが大きいほど速度が平均化されて遅くなる。サイズが小さいほど早く、早いほど結合できる候補が増える
  - サイズが大きい同士をつなげるより、大きいものに小さいものをつなげる方がつなげやすそう。サイズが大きいものの速度の影響は小さい
  - 点のつなぐタイミングは、2点の最適なつなぐ時間は求められる(ABC426E)
  - グループ分け
    - 点と重心速度が近くなるようにする
    - 分割を決めた後に距離を評価する
    - 集合する場所を決めて、そこに集まるように分割
    - 時間順に点をつなぎながら分割方法を決めていく
  - Writer解
    - 最初は団子を適当に決定、最適なつなぐ時間に対して、マッチング問題を解いてつなげる(94位, 751,632,739)
    - マッチング問題を複数回にわけて解く、近い時間のよいものをつなぐと、情報を更新して繰り返す(8位, 852,605,180)
    - フリーの点をペアにする(1位, 921,234,431)
      - フリーとペアの割り当てを決める。線形計画問題
        - グループの合計がKになる
        - 各1回ずつ原子を使う
